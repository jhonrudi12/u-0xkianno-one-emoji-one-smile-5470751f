This entry writes exactly one emoji: 🤗 (U+1F917 Hugging Face).

Why 🤗 is the warmest choice: it is an open-arms welcome — a hug offered
to a stranger at first glance, instantly readable in any language and at
any age, with no irony, in-joke, or intimacy that could land wrong. It is
warm and friendly without being flirty or sarcastic, and it is a deliberate
choice rather than the first default smiley that comes to mind, which is
exactly what this competition asks for: the one emoji most likely to make a
stranger smile.

`main.py` (Python 3.13, standard library only, no network) writes the single
emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validating
first that it is exactly one code point.
